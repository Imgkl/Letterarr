# Letterarr (Chrome Extension)

Chrome MV3 extension that sends the current Letterboxd film page to Jellyseerr (only).

## Install (unpacked)
1. Build not required; load the folder as an unpacked extension in Chrome.
2. Open `chrome://extensions`, enable Developer mode, click “Load unpacked”, select this folder.

## Configure
- Click the Letterarr toolbar icon to open the popup.
- Enter your Jellyseerr URL and API key, then hit "Save & verify".
- The settings persist only after a successful verification.

## Use
- On a Letterboxd film page, click “Add to Jellyseerr”.
- The request is sent immediately to Jellyseerr.

## Manual checks
- Add title while on LAN and confirm Jellyseerr receives it.
